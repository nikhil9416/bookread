Most calculators and computer software will also provide you with the correlation coefficient, a measure of how closely the line fits the data. Correlation Coefficient The correlation coefficient is a value, r, between -1 and 1. r > 0 suggests a positive (increasing) relationship r < 0 suggests a negative (decreasing) relationship The closer the value is to 0, the more scattered the data The closer the value is to 1 or -1, the less scattered the data is The correlation coefficient provides an easy way to get some idea of how close to a line the data falls. We should only compute the correlation coefficient for data that follows a linear pattern; if the data exhibits a non-linear pattern, the correlation coefficient is meaningless.
