Section 5.3 Points on Circles Using Sine and Cosine 369 Reference Angle An angle’s reference angle is the size of the smallest angle to the horizontal axis. A reference angle is always an angle between 0 and 90 degrees, or 0 and 2 π radians. Angles share the same cosine and sine values as their reference angles, except for signs (positive or negative) which can be determined from the quadrant of the angle.
