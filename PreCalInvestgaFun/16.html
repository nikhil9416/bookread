6 Chapter 1 Try it Now 4. Using the function in Example 7, evaluate g(4) Graphs as Functions Oftentimes a graph of a relationship can be used to define a function. By convention, graphs are typically created with the input quantity along the horizontal axis and the output quantity along the vertical. The most common graph has y on the vertical axis and x on the horizontal axis, and we say y is a function of x, or y = f(x) when the function is named f. Example 8 Which of these graphs defines a function y=f(x)? Which of these graphs defines a one- to-one function?
