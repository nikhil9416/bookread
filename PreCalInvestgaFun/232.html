Vertical Asymptotes and Holes of Rational Functions The vertical asymptotes of a rational function will occur where the denominator of the function is equal to zero and the numerator is not zero. A hole occurs in the graph of a rational function if an input causes both numerator and denominator to be zero. In this case, factor the numerator and denominator and simplify; if the simplified expression still has a zero in the denominator at the original input the original function has a vertical asymptote at the input, otherwise it has a hole.
