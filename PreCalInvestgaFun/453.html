Section 6.5 Modeling with Trigonometric Functions 443 Modeling with sinusoidal functions Many modeling situations involve functions that are periodic. Previously we learned that sinusoidal functions are a special type of periodic function. Problems that involve quantities that oscillate can often be modeled by a sine or cosine function and once we create a suitable model for the problem we can use that model to answer various questions.
