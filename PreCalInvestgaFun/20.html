When learning to read, we start with the alphabet. When learning to do arithmetic, we start with numbers. When working with functions, it is similarly helpful to have a base set of elements to build from. We call these our “toolkit of functions” – a set of basic named functions for which we know the graph, equation, and special features. For these definitions we will use x as the input variable and f(x) as the output variable.
