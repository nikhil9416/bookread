Section 2.5 Absolute Value Functions 151 The graph of an absolute value function will have a vertical intercept when the input is zero. The graph may or may not have horizontal intercepts, depending on how the graph has been shifted and reflected. It is possible for the absolute value function to have zero, one, or two horizontal intercepts.
