67 Method references The lambda expression has a signature compatible with the function descriptor of Comparator. Using the recipes described previously, the example can also be written using a method reference; this results in more concise code, as follows: List<String> str = Arrays.asList("a","b","A","B"); str.sort(String::compareToIgnoreCase); Note that the compiler goes through a similar type-checking process as for lambda expressions to figure out whether a method reference is valid with a given functional interface. The signature of the method reference has to match the type of the context. To check your understanding of method references, do try quiz 3.6!
