It’s a much simpler problem to solve if you adopt par- allel streams! 7.1.1 Turning a sequential stream into a parallel one You can make the former functional reduction process (summing) run in parallel by turn- ing the stream into a parallel one; call the method parallel on the sequential stream: public long parallelSum(long n) { return Stream.iterate(1L, i -> i + 1) .limit(n) .parallel() .reduce(0L, Long::sum); } In the previous code, the reduction process used to sum all the numbers in the stream works in a way that’s similar to what’s described in section 5.4.1. The difference is that the stream is now internally divided into multiple chunks. As a result, the reduction operation can work on the various chunks independently and in parallel, as shown in figure 7.1.
