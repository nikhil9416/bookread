365 Evolving Java support for expressing concurrency In this chapter, we focus on richer forms of concurrency in which threads created (or tasks spawned) by a user’s method call may outlive the call, as shown in figure 15.6. This type of method is often called an asynchronous method, particularly when the ongoing spawned task continues to do work that’s helpful to the method caller. We explore Java 8 and 9 techniques for benefiting from such methods later in this chap- ter, starting in section 15.2, but first, check the dangers:  The ongoing thread runs concurrently with the code following the method call and therefore requires careful programming to avoid data races.  What happens if the Java main() method returns before the ongoing thread has terminated? There are two answers, both rather unsatisfactory: – Wait for all such outstanding threads before exiting the application. – Kill all outstanding threads and then exit. Figure 15.4 Strict fork/join.
