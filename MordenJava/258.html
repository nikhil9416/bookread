In addition, it has the same function descriptor as Predicate<String>. As a result, instead of declaring new classes to implement different strategies, you can pass more concise lambda expressions directly: Validator numericValidator = new Validator((String s) -> s.matches("[a-z]+")); boolean b1 = numericValidator.validate("aaaa"); Validator lowerCaseValidator = new Validator((String s) -> s.matches("\\d+")); boolean b2 = lowerCaseValidator.validate("bbbb"); As you can see, lambda expressions remove the boilerplate code that’s inherent to the strategy design pattern.
