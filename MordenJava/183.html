You then collect the elements in each bucket with the downstream collector and so on to achieve n-level groupings! 6.3.3 Collecting data in subgroups In the previous section, you saw that it’s possible to pass a second groupingBy collec- tor to the outer one to achieve a multilevel grouping. But more generally, the second collector passed to the first groupingBy can be any type of collector, not just another groupingBy. For instance, it’s possible to count the number of Dishes in the menu for each type, by passing the counting collector as a second argument to the groupingBy collector: Map<Dish.Type, Long> typesCount = menu.stream().collect( groupingBy(Dish::getType, counting())); The result is the following Map: {MEAT=3, FISH=2, OTHER=4} Also note that the regular one-argument groupingBy(f), where f is the classification function is, in reality, shorthand for groupingBy(f, toList()).
