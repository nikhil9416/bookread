CREATING A BASIC LINKED LIST Recall that you can define a simple linked-list-style class called MyLinkedList in Java by writing it as follows (with a minimal MyList interface): interface MyList<T> { T head(); MyList<T> tail(); default boolean isEmpty() { return true; } } class MyLinkedList<T> implements MyList<T> { private final T head; private final MyList<T> tail; public MyLinkedList(T head, MyList<T> tail) { this.head = head; this.tail = tail; } public T head() { return head; } public MyList<T> tail() { return tail; } public boolean isEmpty() { return false; } } class Empty<T> implements MyList<T> { public T head() { throw new UnsupportedOperationException(); } public MyList<T> tail() { throw new UnsupportedOperationException(); } } Now you can construct a sample MyLinkedList value as follows: MyList<Integer> l = new MyLinkedList<>(5, new MyLinkedList<>(10, new Empty<>())); CREATING A BASIC LAZY LIST An easy way to adapt this class to the concept of a lazy list is to cause the tail not to be present in memory all at once, but to have the Supplier<T> that you saw in chapter 3 (you can also see it as being a factory with a function descriptor void -> T) produce the next node of the list.
