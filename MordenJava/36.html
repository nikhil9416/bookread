3 Java 8, 9, 10, and 11: what’s happening? Since the release of Java Development Kit (JDK 1.0) in 1996, Java has won a large following of students, project managers, and programmers who are active users. It’s an expressive language and continues to be used for projects both large and small. Its evolution (via the addition of new features) from Java 1.1 (1997) to Java 7 (2011) has been well managed. Java 8 was released in March 2014, Java 9 in Sep- tember 2017, Java 10 in March 2018, and Java 11 planned for September 2018. The question is this: Why should you care about these changes? 1.1 So, what’s the big story?
