Doing so allows you to take advantage of the pros of the various DSL styles, but this technique has a minor drawback: the result- ing DSL appears to be less uniform than one that uses a single technique, so users of this DSL probably will need more time to learn it. So far, you’ve used lambda expressions, but, as the Comparator and Stream APIs show, using method references can further improve the readability of many DSLs.
