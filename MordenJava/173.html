These are used when the property to be collected is a primitive-type long or a double. 6.2.3 Joining Strings The collector returned by the joining factory method concatenates into a single string, all strings resulting from invoking the toString method on each object in the stream. This means you can concatenate the names of all the dishes in the menu as follows: String shortMenu = menu.stream().map(Dish::getName).collect(joining()); Note that joining internally makes use of a StringBuilder to append the generated strings into one.
