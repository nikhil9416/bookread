This splitting process can also be influenced by the characteristics of the Spliterator itself, which are declared via the characteristics method. THE SPLITERATOR CHARACTERISTICS The last abstract method declared by the Spliterator interface is characteristics, which returns an int encoding the set of characteristics of the Spliterator itself. The Spliterator clients can use these characteristics to better control and optimize its usage. Table 7.2 summarizes them. (Unfortunately, although these conceptually over- lap with characteristics of a collector, they’re coded differently.) The characteristics are int constants defined in the Spliterator interface.
