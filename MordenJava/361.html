328 CHAPTER 13 Default methods Now consider what would happen if C were inheriting from D as follows (illustrated in figure 13.6): public class D implements A{ } public class C extends D implements B, A { public static void main(String... args) { new C().hello(); } } Rule 1 says that a method declaration in the class takes priority. But D doesn’t override hello; it implements interface A. Consequently, it has a default method from inter- face A. Rule 2 says that if there are no methods in the class or superclass, the method with the most specific default-providing interface is selected. The compiler, therefore, has a choice between the hello method from interface A and the hello method from interface B. Because B is more specific, the program prints "Hello from B" again.
