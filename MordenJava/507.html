474 CHAPTER 19 Functional programming techniques import java.util.function.Supplier; class LazyList<T> implements MyList<T>{ final T head; final Supplier<MyList<T>> tail; public LazyList(T head, Supplier<MyList<T>> tail) { this.head = head; this.tail = tail; } public T head() { return head; } public MyList<T> tail() { return tail.get(); } public boolean isEmpty() { return false; } } Calling the method get from the Supplier causes the creation of a node of the Lazy- List (as a factory would create a new object). Now you can create the infinite lazy list of numbers starting at n as follows. Pass a Supplier as the tail argument of the LazyList constructor, which creates the next element in the series of numbers: public static LazyList<Integer> from(int n) { return new LazyList<Integer>(n, () -> from(n+1)); } If you try the following code, you see that it prints 2 3 4. Indeed, the numbers are gen- erated on demand.
