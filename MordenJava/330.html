297 New Date and Time API The Java API includes many useful components to help you build complex applica- tions. Unfortunately, the Java API isn’t always perfect. We believe that the majority of experienced Java developers will agree that date and time support before Java 8 was far from ideal. Don’t worry, though; Java 8 introduces a brand-new Date and Time API to tackle this issue. In Java 1.0, the only support for date and time was the java.util.Date class. Despite its name, this class doesn’t represent a date, but a point in time with milli- second precision.
