But flatMap has the effect of replacing each generated stream with the contents of that stream. In other words, all the separate streams that are generated by the function get amalgamated or flattened into a single stream. What you want here is something similar, but you want to flatten a two-level optional into one. As figure 11.2 does for the map method, figure 11.4 illustrates the similarities between the flatMap methods of the Stream and Optional classes. Here, the function passed to the stream’s flatMap method transforms each square into another stream containing two triangles. Then the result of a simple map is a stream containing three other streams, each with two triangles, but the flatMap method flattens this two-level stream into a single stream containing six triangles in total. In the same way, the function passed to the optional’s flatMap method trans- forms the square contained in the original optional into an optional containing a tri- angle. If this function were passed to the map method, the result would be an optional containing another optional that in turn contains a triangle, but the flatMap method flattens this two-level optional into a single optional containing a triangle.
