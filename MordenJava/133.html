For example, the following code filters all even num- bers from a list and then eliminates duplicates (using the equals method for the com- parison). Figure 5.2 shows this visually. List<Integer> numbers = Arrays.asList(1, 2, 1, 3, 3, 2, 4); numbers.stream() .filter(i -> i % 2 == 0) .distinct() .forEach(System.out::println); 5.2 Slicing a stream In this section, we’ll discuss how to select and skip elements in a stream in different ways.
