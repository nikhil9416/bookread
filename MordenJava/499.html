466 CHAPTER 19 Functional programming techniques This code is clearly functional-style (uses no mutation, even locally) and doesn’t mod- ify any existing data structures. Note, however, that the code doesn’t create a new TrainJourney. If a is a sequence of n elements and b is a sequence of m elements, the code returns a sequence of n+m elements, in which the first n elements are new nodes and the final m elements share with TrainJourney b. Note that users are required not to mutate the result of append because by doing so, they may corrupt the trains passed as sequence b.
