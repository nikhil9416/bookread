102 CHAPTER 5 Working with streams The dropWhile operation is the complement of takeWhile. It throws away the ele- ments at the start where the predicate is false. Once the predicate evaluates to true it stops and returns all the remaining elements, and it even works if there are an infinite number of remaining elements! 5.2.2 Truncating a stream Streams support the limit(n) method, which returns another stream that’s no lon- ger than a given size. The requested size is passed as argument to limit. If the stream is ordered, the first elements are returned up to a maximum of n. For exam- ple, you can create a List by selecting the first three dishes that have more than 300 calories as follows: List<Dish> dishes = specialMenu .stream() .filter(dish -> dish.getCalories() > 300) .limit(3) .collect(toList()); Figure 5.3 illustrates a combination of filter and limit. You can see that only the first three elements that match the predicate are selected, and the result is immedi- ately returned.
